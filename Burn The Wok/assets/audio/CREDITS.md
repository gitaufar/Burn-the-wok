# Kredit audio

Semua file di tabel pertama berlisensi **CC0 (domain publik)**, diambil dari OpenGameArt.org dan Kenney.nl pada 13/11/2026. File di tabel kedua berasal dari tim dan **lisensinya belum diverifikasi** (lihat catatan di bawahnya). CC0 tidak mewajibkan atribusi, tetapi tabel ini dicatat untuk laporan (daftar sumber aset).

Cara pengolahan: SFX diubah ke WAV mono 16-bit 44,1 kHz, keheningan di awal/akhir dipotong (kecuali loop), dinormalisasi ke -3 dB. Musik disimpan sebagai OGG: WAV stereo bisa 15 MB atau lebih per lagu, dan musik berformat WAV dari sumber (Tropical Loop) dikonversi ke OGG. Format OGG butuh decoder; lihat catatan di `docs/04-characters-assets.md`.
