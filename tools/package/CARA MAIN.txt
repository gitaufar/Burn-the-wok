BURN THE WO
Tim Dapur Tedduy - Pemrograman Gim, Informatika Universitas Brawijaya

CARA MENJALANKAN
1. Pastikan file zip sudah DIEKSTRAK (klik kanan zip > Extract All...).
   Jangan menjalankan game langsung dari dalam zip.
2. Buka folder hasil ekstrak, klik dua kali "Burn The Wo.exe".
3. Jika muncul layar biru "Windows protected your PC":
   klik "More info" lalu "Run anyway".
   (Muncul karena game belum punya sertifikat digital berbayar, bukan karena virus.)

TUJUAN
  Padamkan semua api sebelum waktu habis. Api yang dibiarkan menyebar ke pohon
  lain, dan pohon yang terbakar terlalu lama berubah menjadi kebun sawit.
  Kalah jika lahan sawit mencapai batas, atau waktu habis saat api masih menyala.

KONTROL
  Enter / Spasi   : mulai dari menu
  W A S D / panah : bergerak
  Klik kiri (tahan): semprot air ke arah kursor mouse
  Isi ulang air   : berdiri di tepi kolam
  Roda mouse      : zoom
  Esc             : kembali ke menu / keluar dari menu
  F1 / F2         : (sementara, untuk uji) langsung ke layar menang / kalah
  F4              : (sementara, untuk uji) bakar pohon di bawah kursor mouse

KEBUTUHAN SISTEM
  - Windows 10 atau 11 (32-bit atau 64-bit)
  - Kartu grafis yang mendukung OpenGL 3.3 (hampir semua laptop sejak 2012)

JIKA ADA MASALAH
  - "SDL2.dll / glew32.dll was not found": zip belum diekstrak, atau file .dll
    terpisah dari .exe. Semua file harus tetap satu folder.
  - "OpenGL 3.3 context creation failed": update driver kartu grafis.

Folder "licenses" berisi lisensi library pihak ke-3 (SDL2, GLEW) yang dipakai engine.
